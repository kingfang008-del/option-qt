# 毒性回调触发信号解剖（假突破 / 深亏）

**日期：** 2026-07-19  
**样本：** L2+TT1_05+sl55 · May–Jul 57 笔 + Feb–Apr 76 笔  
**产物：** `results/entry_factor_toxic_autopsy_sl55/`  
**问题：** 深度回调（期权 ≤−25% / SL）是由什么触发的？入场前能否挖因子防范？

## 1. 结论先讲

| 问题 | 答案 |
|------|------|
| 入场前因子能否稳定区分毒性单？ | **基本不能**（与赢家高度重叠） |
| 回调的可观测触发在哪？ | **入场后 1–5 分钟**：期权 MTM 单边阴跌，正股仅轻微逆向 |
| 能否用「触发」做防范？ | 属于**持仓早期路径**，不是入场门；与已 REJECT 的 `mae_cut` 同源 |
| 还有没有可挖的？ | 只剩**极窄早期路径签名**（未印 MFE + 快速挖坑），需单独双窗验收，预期仍水床 |

## 2. 入场前：几乎不可分

毒性 vs 赢家在 Rule-A / feature_ts 上：

| 因子 | win 均值 | toxic 均值 | 可分性 |
|------|---------:|-----------:|--------|
| `|fp|` | 3.2% | 2.8% | 弱（毒性甚至更不「追」） |
| peer | 5.4 | 5.4 | 无 |
| mf 同向 | ~99% | **100%** | 无（毒性入场时资金仍确认） |
| `mf_fast` 逆向 | 15% | 15% | 无 |
| 近 5/10m 正股同向推进 | 有 | 有 | 无 |
| QQQ mf 同向 | 81% | **90%** | 反直觉偏毒性更高 |

强窗 4 笔毒性在入场时 **全部 mf 仍同向**，`dmf_5` 也多为正（资金仍在加码），**不是「信号已经坏了还进」**。

因果闸扫描（入场前拒单）在强窗上：**挡不住这 4 笔毒性**；`dmf_5<0` 等只会误杀赢家。  
弱窗上 `dmf_5<0` 看似抬期望，但是**窗依赖**，不能当全局因子。

## 3. 真正的触发：入场后路径

| 入场后标记 | win | toxic | 含义 |
|------------|----:|------:|------|
| 期权 MTM @3m | **+7.1%** | **−10.2%** | 3 分钟已分叉 |
| 期权 MTM @5m | +9.2% | −14.4% | |
| 10m 内 MAE | −12% | **−30%** | |
| 10m 内 MFE | +34% | **+7%** | 毒性几乎没印过盈利 |
| 首次触 −20% 用时 | ~3500s | **~375s** | 约 6 分钟内砸穿 |
| 正股同向 @5m | +0.13% | −0.09% | 正股只动一点点 |

叙事还原（强窗）：

1. **05-06 NVDA UP**：入场仍顺；1m 期权 −4%，3m −20%，5m −28%；正股 5m 仅 −0.32%。  
2. **05-11 TSLA DN**：同向；~5m 期权 −21%，~17m SL；正股翻红量级 0.1–0.2%。  
3. **06-24 GOOGL UP**：2m 内已接近 −20%；MFE 为负。  
4. **06-24 AMD UP**：期权阴跌较慢，偏「磨」不是闪崩。

→ **触发器 =「权利金对微小逆向的杠杆放大 + 从未走出 MFE」**，不是指数级反转，也不是入场时 mf 翻脸。

## 4. 对「挖因子防范」的含义

```text
入场时因子 ──(信息弱)──×──> 防毒性
                │
入场后 1–5m 路径 ──(信息强)──> 可识别毒性雏形
                │
                └─ 但与 mae_cut / 早切 同类：赢家也会先挖 −10%~−20%
```

早期期权阈值诊断（示例）：

- 弱窗 `opt@5m ≤ −15%`：毒性精确率 ~0.62，误伤赢家少  
- 强窗同一规则：精确率 ~0.20，**大量误伤赢家**

因此：

- **不宜**再把希望放在「再找一个入场横截面因子」上挡住 −55% SL。  
- **若**要挖，对象应是持仓早期的**路径签名**（`MFE≈0` ∧ 快速 MAE），并接受与 `mae_cut` 一样的双窗验收，而不是宣称新 alpha。
