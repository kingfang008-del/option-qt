# MAG7 自适应趋势交易架构设计（V2）

## 目标

目标不是预测固定未来30分钟收益，也不是在开盘时猜测“今天最终是不是趋势日”，而是：

> **高召回地发现趋势启动候选，只对实际准备执行的交易做即时质量过滤，并让持仓管理随路径变化。**

核心思想：

    市场状态先验（软）
          ↓
    高召回规则产生候选与方向
          ↓
    按真实策略排序 / 每日 Top2
          ↓
    Entry Validator 只拒绝明显假信号
          ↓
    立即执行
          ↓
    失败检测 + 动态退出

------------------------------------------------------------------------

# 总体架构

                    Market Data
                          │
            ┌─────────────┴─────────────┐
            │                           │
     Price / Volume              Context Data
     VWAP / ATR / RVOL           Breadth / QQQ / Event
            └─────────────┬─────────────┘
                          │
            Causal Multi-scale Features
                          │
                          ▼
            Layer 0 : High-Recall Candidate
                          │
             Smooth / Impulse + Direction
                          │
                          ▼
            Layer 1 : Regime Prior（软）
                          │
              仓位缩放 / 风险预算，不发方向
                          ▼
            Layer 2 : Real Decision Funnel
                          │
               时间排序 / Top2 / 补位
                          │
                          ▼
            Layer 3 : Top2 Entry Validator
                          │
            Allow / Reject（只拒明显假）
                          │
                          ▼
                 Immediate Execution
                          │
                          ▼
            Layer 4 : Failure Detector
                           │
              结构失效则快速退出，否则持有
                           │
                          ▼
            Layer 5 : Dynamic Position Manager

## 关键约束

1. **方向来自候选规则**，Validator 不重新预测 Long/Short。
2. **Regime 只做软仓位调整**，不能在盘初用全天标签硬禁交易。
3. **Validator 的训练对象必须与实盘执行对象一致**：实际 Top2，而不是全部候选池。
4. **默认立即入场**。3～5分钟确认只能用于退出或加减仓研究，不能机械延迟所有交易。
5. **最终验收看完整交易策略**：拒绝、补位、成交成本、动态退出必须一起回放。

# Layer 0：高召回候选生成

## 目标

尽可能早地覆盖大行情的启动阶段，允许存在一定比例假信号。

当前候选体系：

- Own-path Smooth Launch：识别持续、低回撤的平滑启动；
- Impulse Launch：覆盖开盘跳空与短时快速位移；
- 候选规则直接输出 `UP` / `DN`；
- 优先早盘、每标的每方向首发，减少重复候选。

候选层的目标是 **Recall**，不承担最终 Precision。

------------------------------------------------------------------------

# Layer 1：Regime Prior（软状态层）

## 目标

回答“当前环境应承担多少风险”，而不是“今天最终是不是趋势日”。

输出：

- `risk_scale ∈ [0, 1]`
- `normal / caution / event / dislocated`
- 可选 `up_environment / down_environment / neutral`，但不覆盖候选方向

特征必须在决策时可见：

- Overnight Gap / Opening Range
- ATR / Realized Volatility / Relative Volume
- QQQ 与 Mag7 breadth
- 截面相关性与相关性突变
- VIX / 事件日历 / 新闻风险
- 报价陈旧度、点差与流动性状态

禁止：

- 用全天 VWAP 同侧比例等未来信息做盘初特征；
- 把“最终趋势日”标签直接当作开盘硬门；
- 因 QQQ 同向就强制允许或拒绝个股。

------------------------------------------------------------------------

# Layer 2：真实决策漏斗

Validator 之前必须完整复现生产策略：

1. 按候选时间排序；
2. 应用每标的去重；
3. 应用每日最多持仓数（当前 Top2）；
4. 如果 Validator 拒绝某候选，后续候选按相同规则补位；
5. 组合相关性、并发仓位和日内风险预算在此层生效。

研究数据的样本单位不是“一个任意 launch”，而是：

> **某日某时刻，策略准备占用的一个真实交易席位。**

全候选池的 AUC、Precision 只能用于诊断，不能作为上线依据。

------------------------------------------------------------------------

# Layer 3：Top2 Entry Validator

## 角色

Validator 只做高置信拒绝：

- `ALLOW`：没有足够证据否定候选；
- `REJECT`：属于最容易识别的明显假信号；
- 不负责寻找新 Alpha；
- 不负责输出 Call/Put 或重新判断方向。

## 标签：First-Passage 三分类

从真实决策时点开始，在固定研究上限内观察先触及哪一侧：

- **Clear True**：先达到正向 MFE（例如 +1.0%），且此前 MAE 不超过预算；
- **Clear False/Toxic**：先触及反向 MAE（例如 -0.4%～-0.6%），未先形成有效 MFE；
- **Ambiguous**：两侧都未明确触发，第一版不用于训练硬分类。

阈值必须用 ATR / 实现波动率做归一化对照，固定百分比仅作为基线。

## 特征

只使用入场时可见信息：

- 3 / 5 / 10 / 20分钟多尺度路径效率；
- 净位移、回撤、从极值恢复、连续性；
- ATR-normalized move / drawdown；
- RVOL、量价一致性、VWAP距离、Opening Range位置；
- Mag7 breadth、相关性、指数环境；
- 时段、事件、新闻、流动性。

滑动窗口可以作为**多尺度特征**，不能继续作为单一机械硬门。

## 模型

第一版使用 LightGBM：

- 训练目标优先 `P(clear_false)` 或 reject ranking；
- 使用代价敏感训练，真信号误杀成本高于漏放假信号；
- 不以整体 AUC 为主目标；
- Transformer 仅在表格模型和样本规模证明不足后再考虑。

# Entry Execution

默认在候选通过即时 Validator 后执行，不统一等待回踩或固定确认窗。

原因：

- 滚动 OOS 显示，机械等待3～5分钟会丢失启动阶段收益；
- Pullback 并非所有趋势路径都会出现；
- Smooth 与 Impulse 需要不同执行方式。

Pullback Entry 只能作为独立 sleeve：

- Smooth 可研究限价回踩；
- Impulse 默认不强制等待；
- 必须与立即入场做独立 OOS 对照。

------------------------------------------------------------------------

# Layer 4：Failure Detector

入场后的短时信息用于判断“启动是否失败”，而不是决定是否延迟入场。

候选失败证据：

- 价格跌破启动结构低点；
- 快速失守 VWAP / Opening Range；
- 路径效率显著衰减并出现反向位移；
- 放量反转或流动性突然恶化；
- 个股与自身驱动失配，而非仅因 QQQ 短时反向。

Failure Detector 输出：

- `HOLD`
- `REDUCE`
- `EXIT`

必须验证快速退出节省的亏损是否大于被洗掉的真趋势利润。

------------------------------------------------------------------------

# Layer 5：Dynamic Position Manager

禁止把固定持仓30分钟作为主要退出逻辑。

建议：

- 波动率自适应 Trailing Stop；
- 启动结构 / VWAP 失守退出；
- Trend Score 持续衰减退出；
- ROI / Delta 停滞退出；
- 时间止损只处理“没有发展”的仓位；
- EOD 强平与灾难止损保留。

不同 sleeve 使用不同退出：

- Smooth：给趋势更大空间，避免小回撤反复止损；
- Impulse：更重视冲高回落与快速失效；
- 期权执行必须使用真实 ask-in / bid-out 或统一 fill 模型。

------------------------------------------------------------------------

# 数据集与防泄漏

## 样本范围

2026年约只有250个实际 Top2 样本，不足以稳定训练。第一阶段应扩展到2024～2026：

- 目标至少1000～1500个真实决策席位；
- 保留 symbol、时段、波动率和市场状态分层；
- 对历史数据执行与实盘完全相同的候选、排序、Top2和补位逻辑。

## 因果时间

每一列必须记录：

- `event_ts`：市场事件发生时间；
- `available_ts`：实时系统可见时间；
- `decision_ts`：策略决策时间。

任何 `available_ts > decision_ts` 的特征不得进入训练。

## 切分

- 禁止随机切分；
- 使用 expanding / rolling walk-forward；
- 阈值只在过去的 calibration 窗确定；
- 月度或 regime 分段报告，不能只看合并总收益。

------------------------------------------------------------------------

# 验收标准

## Validator 分类 KPI

在真实 Top2 / 补位决策上：

- `FA_removed ≥ 20%`；
- `true_signal_loss ≤ 10%`；
- `reject_precision ≥ 80%`；
- 至少3个独立 OOS 窗方向一致。

若样本扩大后稳定，再将目标提高到 `FA_removed ≥ 25%～30%`。

## 策略 KPI

必须同时满足：

- 拒绝后补位计入；
- 实际交易数没有因过滤失真；
- 股票或统一 fill 口径下收益提升；
- MaxDD、最差日和连续亏损不恶化；
- 改善不能由1～3笔交易贡献大部分；
- live/replay 信号、时间戳与成交假设一致。

模型不满足策略 KPI，即使 AUC 更高也不得上线。

------------------------------------------------------------------------

# 风险控制

## 每日

- 连续止损后的降仓/停止交易；
- 最大日亏损限制与强制平仓；
- FOMC、CPI、财报等事件使用显式风险模式；
- 数据陈旧、断流、时钟漂移时禁止新开仓；
- 熔断只能限制后续风险，不能替代入场质量。

## 仓位

- 单笔固定风险，而非固定名义金额；
- Regime 只调整风险规模，不修改方向；
- 避免高度相关标的同时重仓；
- 组合级 Delta、行业集中度和并发仓位限制；
- 正股为研究基准，0DTE 不作为早期 Validator 的放大器。

------------------------------------------------------------------------

# 为什么采用这种架构

旧架构：

    固定窗口 / 预测未来30分钟
            ↓
    全候选统一规则
            ↓
    固定持有或机械退出

问题：

- 固定窗口对新 regime 缺乏适应性；
- 回测可因窗口与历史分布偶合而漂亮；
- 全候选分类与真实 Top2 执行对象错位；
- 等待确认会错失趋势最初利润；
- 固定退出会截断赢家或长期持有失败信号。

新架构：

    规则产生候选信号
            ↓
    真实 Top2 决策漏斗
            ↓
    即时 Validator 高置信拒绝
            ↓
    立即执行
            ↓
    Failure Detector + Dynamic Exit

优点：

- 候选、过滤、执行、退出职责清晰；
- 模型优化对象与实盘交易对象一致；
- 只解决可识别的明显假信号，不要求统一解释全部 FA；
- 市场状态通过归一化与软风险预算体现；
- 每层都能独立做因果回放与停止判断。

## 已验证不应采用

- QQQ 同向硬门；
- QQQ TFT 作为 Mag7 侧信道硬门；
- 全候选池 LGBM 直接上线；
- 统一等待3～5分钟确认后入场；
- 入口规则与确认模型简单串联的两段式硬拒；
- 固定30分钟作为主要持仓逻辑。

------------------------------------------------------------------------

# 后续研究路线

## Phase 0：冻结候选生成器

- 固定 Smooth ∨ Impulse 候选定义；
- 固定生产排序、Top2、去重与补位逻辑；
- 不再同时修改 Alpha、标签和 Validator。

## Phase 1：重建真实决策数据集

- 回放2024～2026；
- 生成每个真实交易席位及其补位链；
- 建立 ATR-normalized first-passage 标签；
- 审计 event/available/decision 时间。

## Phase 2：Top2 即时 Validator

- LightGBM clear-true vs clear-false；
- 在 calibration 中选择 reject threshold；
- 按月 walk-forward；
- 达不到 Top2 KPI 即停止，不转向更复杂模型。

## Phase 3：Failure Detector / Dynamic Exit

- 研究入场后1～10分钟的结构失效；
- 对照快速退出、减仓、动态 trail；
- Smooth 与 Impulse 分开验收。

## Phase 4：Shadow

- 股票或小规模低杠杆影子运行；
- 每日核对 candidate → Top2 → validator → fill → exit；
- 累积足够新 regime 后再决定是否接入期权。

## 停止条件

出现以下任一情况应停止当前分支：

- 3个滚动 OOS 中只有1个改善；
- 收益改善主要来自少于5笔替换；
- true signal loss 超过10%；
- 阈值跨月明显漂移；
- replay 与 live 的候选或时间戳不一致。

------------------------------------------------------------------------

# 核心原则

1. Rule 负责高召回和方向，模型只负责高置信拒绝。
2. Validator 必须训练在真实会执行的决策席位上。
3. Regime 是软风险先验，不是盘初全天趋势日硬门。
4. 多尺度滑动窗口是特征，不是机械交易时钟。
5. 默认立即执行；新信息优先用于失败退出，而非统一延迟入场。
6. 模型优先做可解释分类，不直接预测期权收益。
7. 策略级 OOS 改善优先于 AUC、Recall 或漂亮 replay。
8. 长期稳定性、因果性和 live parity 优先于短期收益。
