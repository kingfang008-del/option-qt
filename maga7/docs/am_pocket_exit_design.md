# AM 口袋退出设计（前视路径 → 可交易退出）

> 工具：`tools/scan_am_pocket_exit_design.py`  
> 产物：`results/research_am_pocket_exit_design/`  
> 组合层：`@20% / 5 并发`

## 退出怎么定（方法论）

不要先拍 TP/SL。用**同入场**上的前视路径统计定参数族：

| 线索 | 含义 | 退出动作 |
|------|------|----------|
| `p50_mae_before_mfe` | 见顶前最大回撤 | 硬 SL 应贴在该分位附近（过松吃大亏，过紧砍赢家） |
| `p50_t_to_+8/+15` | 利润到达速度 | 到得快 → 可早 arm；固定低 TP 会截断大 MFE |
| `p50_giveback_after_mfe` | 见顶后吐回 | 大吐回 → 需要 trail / 利润地板，而非死拿 |
| `p50_mfe` vs 因果均值 | 捕获缺口 | 衡量固定规则离 oracle 多远 |

## 稳健入场路径诊断（`no_b_up + vd_soft`，n=65）

| 指标 | 值 |
|------|---:|
| 触及 +8% / +15% / +20% | 89% / 80% / 71% |
| p50 MFE | **+39%** |
| p50 MAE（见顶前） | **−8.2%** |
| p50 见顶持有 | ~255s |
| p50 见顶后吐回 | **~47pp** |
| p50 到达 +8% | ~8s（极快） |

解读：边在**短脉冲 MFE**，不是死拿；吐回极大 → 理论上 trail 有空间；但脉冲极快 + 期权噪声大，简单 trail 容易「刚 arm 就踩回撤」。

`dn_heavy`（n=204）类似，但到达更慢（p50 到 +8% ~22s），MFE 略低（p50 ~29%）。

## 退出族扫描结果（@20%/5）

扫描：`tpsl` / `trail(arm+giveback)` / `profit-protect` / `hybrid(+time_cut)`，共 ~120 格。

| 宇宙 | 最佳（软门槛） | 笔胜率 | maxDD | 复利 | 前视捕获 |
|------|----------------|-------:|------:|-----:|---------:|
| **robust** | **仍是 `TP8/SL15/h240`** | 69% | **−16%** | +33% disc | ~9% |
| robust | `TP10/SL15/h300`（略稳） | 65% | **−15%** | +32% | ~9% |
| dn_heavy | 仍是 `TP8/SL15/h240` | 65% | −20% | +92% | ~7% |

- **Trail / PP / Hybrid 中位数全面弱于固定 TP/SL**（胜率更低、回撤更差或捕获更低）。
- 抬高 TP（如 TP20/SL25）可抬捕获与复利，但 robust 上 maxDD 恶化到 **−37%**——这就是「之前回撤太大」的来源。
- 在「胜率不掉太多」的约束下，**没有退出族把 maxDD 从 −16% 再压到 −10% 以下且保持收益**。

## 结论：回撤还有没有大幅优化空间？

| 目标 | 空间 | 说明 |
|------|------|------|
| 相对旧 `TP20/SL25` 压回撤 | **已兑现** | −28% → −16%（入场过滤 + 低 TP） |
| 在稳健规则上再压一大截 DD | **小** | 路径 MAE 分位已在 −8%；再紧 SL 会砍赢家，trail 实测未占优 |
| 逼近前视捕获（~40–50% 单笔） | **大，但不是 DD 问题** | 当前捕获 ~9%；缺口在「不知何时是顶」，固定/简单 trail 解不开 |
| 下一刀（若还要动退出） | 分档减仓 / 状态条件退出 | 半仓 TP8 + 余仓宽 trail；或失败时间切（180s 仍红则砍）——需单独验收，本次网格未胜出 |

## 实操建议

1. **生产默认退出**：稳健宇宙可升到分档规则（见 `docs/am_pocket_scaleout.md`）：`67%@+6%` + 余仓宽 trail；纯 `TP8/SL15/h240` 仍是稳妥基线。
2. **不要用抬 TP 换收益** 除非接受 maxDD 回到 −25%+。
3. **回撤继续压**：仓位/并发/日损熔断仍是主杠杆；退出侧分档可再压约 1–3pp maxDD。
4. 全仓 trail 已否定；分档减仓见 `research_am_pocket_scaleout`。
